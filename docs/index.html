ESP AdBlock Round

A network DNS ad blocker with a local web dashboard, recent blocked-query history and an optional round touchscreen with swipe navigation and dashboard QR.

The primary tested board is the Guition JC3636W518C: ESP32-S3, 16 MB flash, 8 MB PSRAM, ST77916 360×360 QSPI display and CST816 touch. Separate profiles cover headless S3/C3 and ESP32-2424S012C.

Identify your exact board and back up its flash before a first installation. Release application images are for compatible OTA layouts; they are not complete first-install images. Firmware updates preserve saved settings; filesystem uploads replace existing lists and settings.

DNS blocking cannot reliably remove YouTube ads hosted on content domains. Use administration only on a trusted LAN.
